# RAFTOP CPAP CARE Pro - Support Request Form

Use this format for support issues.

Required fields:

- date:
- requester name:
- requester role:
- affected user:
- affected route/screen:
- issue category:
- severity:
- description:
- expected behavior:
- actual behavior:
- screenshot attached if safe:
- patient reference if allowed:
- data file involved: yes/no
- urgency reason:
- business impact:

Issue categories:

- access
- data
- ATLAS workflow
- compliance view
- reports
- tenant/user role
- support clarification
- change request

Do not include:

- passwords
- tokens
- secrets
- database URLs
- uncontrolled patient identifiers

Rule:

Incomplete support requests may require clarification before action.
