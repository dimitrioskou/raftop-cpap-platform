# RAFTOP CPAP CARE Pro — Screenshot Backup Checklist

## Purpose

This folder contains backup screenshots for the buyer presentation.

Use these screenshots if:

- production frontend is slow,
- Render is waking up,
- internet connection is unstable,
- login takes time,
- a route does not load during live demo,
- buyer asks for quick visual summary.
