## Rules

The buyer enters up to 20 patients manually.

Allowed data:
- patient code
- device serial
- device model
- setup date
- month start
- last data date
- usage hours
- days used
- AHI
- leak
- doctor code
- branch code

Not allowed:
- direct patient identity
- direct contact data
- national identification data
- residential data

## Decision after pilot

After 2 months:
- purchase decision
- support contract
- full rollout planning
- real approved CSV rollout if required
